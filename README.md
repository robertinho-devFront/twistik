# Twistik

Apprendre le Rubik's Cube en jouant, sur un cube 3D directement dans le navigateur.

- **Apprendre** : 15 leçons guidées, de la notation aux PLL, avec un coach qui accompagne chaque mouvement.
- **Défier** : course contre l'ordinateur (facile, moyen, expert), duel entre amis sur le même appareil, mélange du jour.
- **Légendes** : Superflip, damier, grandes formules et histoire du speedcubing, à rejouer coup par coup.

Site statique en un seul fichier (`index.html`), sans build : Three.js chargé depuis un CDN, polices Google Fonts.
